## "No answer node in n8n"
By design. n8n is only the 20-min scheduler (Schedule Trigger -> HTTP
POST /watchdog/run). The Telegram message is sent by Hermes itself
(notify() in compose/hermes/app/main.py), not by any n8n node.

## Token-consumption analysis (read the actual code)
- A HEALTHY Watchdog run costs ZERO DeepSeek tokens: /watchdog/run
  computes `unhealthy` in pure Python (is_unhealthy) and returns early
  before any model call if nothing is unhealthy. ask_deepseek_watchdog
  is only reached when >=1 service is actually unhealthy.
- Chat is the real cost driver: every inbound chat message triggers one
  classify_chat_message DeepSeek call whose prompt includes full infra
  status + the entire HA entity list. Idle polling costs nothing.
- Notifications only fire on a relevant event (restart taken, or
  unhealthy-but-no-action) -- never a heartbeat.
